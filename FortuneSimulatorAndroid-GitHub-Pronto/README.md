# Fortune Simulator (Android)

Projeto Android pronto para compilação automática via GitHub Actions.

## Como gerar o APK no GitHub
1. Extraia o conteúdo deste ZIP na raiz do seu repositório no GitHub (incluindo a pasta oculta `.github`).
2. Faça o commit/push para a branch `main` (ou `master`).
3. Acesse a aba **Actions** no repositório do GitHub.
4. Aguarde a conclusão do workflow **Build Android APK** e baixe o APK na seção **Artifacts** (`FortuneSimulator-debug-apk`).
